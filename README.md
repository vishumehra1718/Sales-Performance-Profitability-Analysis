\## 🧠 Project Overview



Retail businesses generate large amounts of sales data every day. Analyzing this data helps businesses understand sales performance, identify profitable products, and make better business decisions.



This project focuses on analyzing retail sales performance using \*\*SQL\*\* for business analysis and \*\*Power BI\*\* for interactive dashboard development and data visualization.



\## 🎯 Project Objectives



\- Analyze overall sales performance and profitability.

\- Identify top-performing product categories.

\- Understand regional sales trends.

\- Analyze customer purchasing patterns.

\- Generate business insights for better decision-making.
